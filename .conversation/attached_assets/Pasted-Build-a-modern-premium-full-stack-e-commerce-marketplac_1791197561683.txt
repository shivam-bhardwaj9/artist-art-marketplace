Build a modern, premium, full-stack e-commerce marketplace for artists where independent artists can create their own stores and sell paintings, drawings, digital art, sculptures, photography, prints, and other artwork to customers.

The platform should work like a multi-vendor art marketplace, with two completely different user roles:

1. SELLER / ARTIST
2. BUYER / CUSTOMER

There should also be an ADMIN role for managing the entire platform.

---

Create a premium, artistic, minimal and visually immersive design.

* Luxury art gallery aesthetic

* Elegant typography

Implement secure authentication.

Requirements:

* Email/password authentication
* Password hashing
* JWT or secure session authentication
* Role-based authorization
* Protected seller routes
* Protected buyer routes
* Protected admin routes
* Input validation
* API authorization
* Secure file uploads
* Rate limiting
* Prevent unauthorized artwork modification
* Prevent buyers from accessing seller dashboard
* Prevent sellers from accessing admin functionality

Never rely only on frontend role checks.

Authorization must also be enforced on the backend.

# 33. DEVELOPMENT APPROACH

Build the application as a real full-stack production-ready application.

Do NOT create a static frontend mockup.

All major features should be connected to the backend and database.

Do not use fake hardcoded data for:

* Authentication
* Products
* Orders
* Cart
* Wishlist
* Artist dashboard
* Sales
* Earnings

Create proper database models, API routes and frontend state management.

Seed the database with realistic demo artists and artwork so the UI can be tested immediately.

Create a clean folder structure and reusable components.

Include:

* Environment variables
* Database migrations
* Seed script
* API error handling
* Loading states
* Empty states
* Form validation
* Toast notifications
* Error pages
* 404 page
* Authentication guards
* Role-based route protection

The final result should feel like a real startup-level online art marketplace rather than a simple portfolio website.
